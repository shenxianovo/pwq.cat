# pwq.cat

一间有猫的像素小屋。原生 HTML、CSS 和 JavaScript，插画用 SVG 绘制，字体使用系统字体，所有资源都在本地。

直接用浏览器打开 `index.html`，或在这个目录运行：

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8080>。

点击橘猫或爱心按钮，猫会眯眼并冒出爱心；右上角的图标切换白天与夜晚。浏览器允许本地存储时会记住昼夜选择。

页面适配桌面和手机，按钮支持键盘操作，并遵循系统的减少动态效果设置。部署时把 `index.html`、`style.css`、`script.js` 和 `favicon.svg` 放到静态托管服务的根目录即可。
